# **App Name**: Nilgiri Explorer

## Core Features:

- Tour Package Display: Display available tour packages with details like itinerary, gallery, and overview using a tabbed interface.
- Dynamic Itinerary Tool: Provide a generative AI-powered tool to customize the itinerary based on user preferences, suggesting optimal routes and timings for visiting places.
- Seat Availability Chart: Implement a dynamic seat chart where users can view and select available seats for booking.
- Booking Form: Implement multi-step form that stores passenger data.

## Style Guidelines:

- Primary color: Forest green (#388E3C) to reflect nature and the greenery of the Nilgiri hills.
- Background color: Light beige (#F5F5DC) to provide a neutral and calming backdrop.
- Accent color: Mustard yellow (#FFDA63) for interactive elements like buttons and highlights.
- Body and headline font: 'PT Sans', a humanist sans-serif providing a modern look with a touch of warmth, is ideal for both headlines and body text.
- Use icons that represent landmarks and themes (tea estate, viewpoint, botanical garden) in the tour package.
- Implement a card-based layout for tour packages, ensuring all information is clearly displayed with key details upfront.
